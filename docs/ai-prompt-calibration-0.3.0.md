# 0.3.0 AI 提示词生产语料校准结论

校准时间：2026-08-29，数据源：生产库只读导出（61 张未删卡片 / 3 个已绑定 Case / 19 笔 Trade）。
本文只记录模式级结论与极短引语示例，不整段复制生产原文。

## 语料总体特征

- 语音输入为主：口语重、语气词多（呢/哈/吧/卧槽）、中英混杂（stop order、take profit、measured move；语音转写会把术语写错，如 measured move → 「Mesh move」）。
- 存在整段语音识别噪音（无意义英文句子直接混在卡内）——digest 与拆分提示词都必须容忍噪音段，逐字保留不清洗。
- 卡片长度：中位约 190 字，最长 630 字；一段卡内常含多句、换行分段。
- phase 分布：intermediate 最多（30），pre-entry 次之（21），entry/closing/reflection 各 3-4。

## BAR 引用模式（批量拆卡 F6 + barRef 提取）

真实变体（拆分提示词的锚点识别必须覆盖）：

- 「现在是 BAR 254」「BAR 258 就更糟糕了」「BAR 82号出来」
- 「257 这一根 K 线」「78 号 K 线」「150 号 K 线」
- 「在第 15 根 K 线的底部」「第 17 根 K 线触碰到了…」
- 裸数字开头：「89，价格选择去上涨」
- 省略百位的并列：「266 和 67」「272 和 273」（连读时后一个数是省略形式）
- 同一张卡内可提到多个 BAR（当前锚 + 回顾更早的 BAR）——锚点取「本卡陈述时刻」的那一个，回顾引用不作锚。

## 持仓管理动作表达（Execution 建议 F3）

- 明确型（应建议）：「把我的止损价格移动到 90820.36 这个位置」「止盈的点位…差不多在 91046 的位置，这是我移动了它的止盈」「我修改了我入场的价格到 90767」「我撤销了刚刚设置的这个 sell stop order」「把刚刚那一笔订单再挂回来」。
- 否定型（绝不建议）：「目前不适合移动止盈止损。也没有什么需要改变的」「我决定保留我原有的止损，不向下移动，也不向上移动」。
- 条件型（默认不建议，提示词要求仅在「已经做了」的确定语气下提取）：「如果当前的价格…我就…」。
- 部分仓位型：「下了一个卖出止损单，止损一半的仓位」——有明确动作与对象，可建议但数量语义交给用户在确认时补。
- 生产验证：3 笔已绑定 Trade 中 2 笔管理 execution 为 0 条，而卡片明确说了止损/止盈移动的具体价格——「说了没落库」是真实高频场景。

## digest（F1/F2）

- 每张卡基本都有清晰主题句（观察/计划/动作/情绪/复盘），一句话提炼可行；噪音段直接忽略不进 digest。
- 口语细节多（振幅、区间上下沿、EMA 位置、盈亏比），digest 应保留「最有信息量的一个点」，不是泛泛概括。

## 整单总结（F4）

- closing 卡自带结果叙述（离场原因、盈亏金额、盈亏比），可与机械 metrics 互相印证；总结提示词要求以数字指标为准、卡片叙述为辅，冲突时并列陈述不裁决。
- entry 卡含仓位策略叙述（小/中/大仓位比例），是「计划 vs 实际」的良好素材。

## 顺带发现的存量数据问题（0.3.0 内防御）

- `initialTakeProfit=2`：来自「至少拿到一个 2~3 倍」的 `firstNumberIn` 机械提取（倍数语义被当价格）。
- `initialEntryPrice=64`：来自「在 64 号 K 线的底部去挂单」的 K 线号被当价格。
- 防御方向：① F1 memo 提示词要求价格类字段 value 输出纯数字（明确价格时）并区分「K 线号/倍数」语义；② TS 侧 memo→计划价回填加数量级合理性校验（与该 Trade 实际成交价同一数量级，否则跳过）。
