# CAIRN 0.3.6 Release Notes

0.3.6 是一轮「AI 可靠性 + 可 debug」的打磨：校验失败的 AI 调用会带着上一轮的请求与错误自我修正一轮；仓位数字不再出现 2.4425999999999997 这种浮点尾巴；拆卡有了可选的手动预览；日志模块按日期分文件重做，AI 请求全量可查；还修掉了 0.3.5 确认弹窗下方外溢的灰色横条。无数据库迁移、无 schema 变化。

## 0. 确认弹窗修复：下方的灰色横条

0.3.5 的确认弹窗页脚少了内边距抵消（Popup 缺 `p-4`，页脚的负 margin 向四周外溢 16px），表现为弹窗下方紧贴一条空的灰色圆角横条。已修复并对齐普通 Dialog 的贴边契约。

## 1. AI 校验失败自动修正重试

此前 AI 调用只在网络类失败时自动重试；模型输出**没通过机械校验**（拆卡的逐字/覆盖率、输出不是 JSON）时要么静默降级要么直接报错。现在：

- 校验失败会自动再发一轮：**第一轮的请求与模型原话 + 具体校验错误**作为附加上下文，要求模型修正后重出（temperature=0 下原样重发没有意义，差异完全来自错误信息）。
- 覆盖：批量拆卡（修正仍败才降级整卡，且降级原因进日志）、AI 重拆此卡（修正仍败才报错，错误文案带具体原因）、卡片分析（非 JSON 修正一轮）、补录+标签建议（共用一次调用，同时修正）。
- 整单总结（流式）不走修正轮——markup 清洗永不失败，流文本重发会重复推送。

## 2. AI 标签建议：可教重试 + 要更多标签

「AI 标签建议」面板新增「带着要求重试」入口（与卡片识别/总结的 AiRetryLink 同款）：

- 重试时把你的补充要求连同**标签现状**（Trade 已有标签、此前已应用/已忽略名单）一起发给 AI——「再多给一些」「换个方向」这类要求由此生效。
- 词表放宽一格（仅限带要求的重试）：AI 可以建议你**在要求里明确写过名字的新标签**（应用时自动补建标签定义）；常规检查仍严格限定在你自己的标签词表内。
- 建议调用 prompt 版本 `0.3.6-suggest-3`。

## 3. 手动拆卡：先预览，再落卡

直接拆卡（不预览、流畅优先）保持不变；新增可选预览：

- **浮窗**（v0.3.3）：勾「拆卡」后可再勾「**预览**」。提交后 AI 拆分但**不落库**，弹出拆分预览：每段可改文字、改 BAR、把一段「并入上一张」，底部实时提示未覆盖字数；「确认创建」才落卡，取消（或 Esc）什么都不创建、原文留在输入框。AI 返回单段时跳过预览直接保存。
- **应用内「AI 重拆此卡」**改为两步：先跑 AI 出预览对话框（同样的编辑能力，剩 1 张时不可确认——只想改字请用 ✎），「替换为 N 张」才真正替换；替换前会再核对原卡未被编辑过。
- 手动模式的机械校验放宽为边界校验（1–20 段、非空、BAR 1–1440）——你已经过目，不再强制逐字覆盖率，但未覆盖字数摆在明面上。

## 4. 数字精度：仓位不再带浮点尾巴

`2.4425999999999997` 这类浮点累加噪声会出现在 AI 总结与统计卡里。现在数量统一格式化为**最多 6 位小数并去尾零**（→ `2.4426`），价格按品种精度截断：

- AI 总结上下文（TS）与卡片分析/建议背景块（Rust）全部过格式化——模型不再复述噪声数字。
- UI：总仓位统计卡、交易时间线、图表标记与 hover、编辑弹窗执行摘要。
- 数据层不做舍入，纯展示/上下文格式化。

## 5. 日志模块重做：按日期分文件，AI 请求可 debug

旧的单文件 `cairn.log` 只记起止标记，AI 请求发去了哪、发了什么、回了什么全查不到。现在：

- **`logs/cairn-YYYY-MM-DD.log` 一天一个文件**，同日多次启动写启动分隔头（版本/OS），保留 14 天自动清理；panic 也进当天文件（旧 `cairn.log` 原地保留不再写）。
- 行格式 `[时间] [级别] [来源] 消息`，级别 info/warn/error，前端错误的级别真正接上。
- **AI 请求全量记录**：每次调用记请求（目标主机、Provider、模型、消息数/字符数、请求体）与响应（耗时、字符数、token 用量、响应体），失败带完整错误链；请求/响应体按 16KB 截断，**API Key 永不落盘**。
- 设置 → 日志页升级：日期下拉、级别/关键词过滤、自动刷新（2s）、复制、清空（走确认框）、打开日志目录。

## 升级与兼容

- 无数据迁移、无 schema 变化；建议 blob 的 prompt 版本号随调用更新（`0.3.6-suggest-3`）。
- REST 新增 `POST /cases/:id/cards/split-preview`、`POST /cases/:id/cards/batch-create`；旧 `batch-split` 原样保留。应用内重拆命令拆成 `preview_case_card_resplit` + `apply_case_card_resplit`（GUI only）。
- 浮窗脚本 `@version` 0.3.2 → 0.3.3：设置页会提示 GitHub main 有新版（或直接复制内置新版）；旧浮窗继续用直接拆卡，不受影响。
- 浮窗批量请求超时 200s → 300s（服务端修正轮最坏 ~270s）。
