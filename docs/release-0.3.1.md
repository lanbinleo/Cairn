# CAIRN 0.3.1 Release Notes

0.3.1 是打磨版：修掉 AI 手动链路的「点了没反应」，落地产品经理的文案与信息架构审查（界面从「贴满工程图纸」回到「汽车仪表盘」），外加几个小功能。无数据库迁移、无 schema 变化。

## 1. 修复：AI 总结点了没反应

- 根因：首次生成总结的按钮没有进度提示，错误信息又只渲染在「已有总结」的分支里——没配默认 Provider、网络超时、模型输出解析失败时什么都看不到；运行状态还是组件局部的，切页回来就「复位」了。
- 现在：总结与「AI 补录建议」检查的运行/失败状态提升为全局 store 状态——切页回来仍显示「生成中…」或失败原因；生成失败会在日志页留痕（设置 → 日志/诊断 可查原因）。
- 「填入复盘备注」支持重填：备注已有内容时按钮变「重新填入」，确认后整体替换为最新总结草稿（复盘侧栏的备注展示不变）。

## 2. 浮窗拆卡改显式勾选

- 拆不拆不再靠「≥2 个 K 线锚点」的机械猜测——输入行新增「拆卡」勾选框：勾了走批量拆分，没勾存整卡，用户说了算。
- 勾选时 BAR 输入禁用（拆分锚点来自卡内原话）；勾选状态在连续提交间保留，面板重开复位。同文本重试的幂等逻辑不变。

## 3. Trade 页重排：复盘 / 案例 / 评估

- 三个 tab 中文化并按复盘工作流排序（默认落复盘，内部地址不变）。
- 复盘减负：删掉图表下方二三十张卡撑高的 Case Cards 按钮组（图上的方块标记仍可点击）；侧栏 Case 卡收成一行链接；「结果」只留 PnL、R、进出场均价、持仓时长；「归属」并成紧凑元信息卡；无笔记提及时不渲染空卡。
- AI 整单总结移到案例 tab 顶部（生成入口在那）；交易备注卡常显。
- Trade 页头部：复制 ID / JSON 等开发向操作收进「···」菜单。

## 4. 计划 vs 实际：看得懂、对得上

- 对照卡新增「偏差」列（实际 − 计划），多笔入场标「含加仓」。
- 「录」「卡」单字符图例改为完整标签「补录」「来自卡片」；实际列的来源（入场=全部成交加权均价、止损=最终生效止损含移动、离场=加权均价）进 ⓘ 说明——不再让人猜「实际」从哪来。

## 5. AI 补录建议面板收敛

- 「AI 检查」更名「AI 补录建议」，说明进 ⓘ；全部处理完后整卡收成一行「管理动作都已记录（N 已添加 · M 已忽略）」+ 重新检查，不再占大块空间。
- 展开卡片的 ✎ / 移动 / 删除收进「···」菜单；「已修正 N 次」并入时间 tooltip。Case 页删掉与下拉完全重复的状态只读行。

## 6. 语言与术语统一（PM 审查全量落地）

- 动词统一：AI 整理 → AI 识别（自动识别 / 重新识别 / 全部识别）；标签编辑叫「编辑标签」。
- 过期三说法统一为「需重新识别」；「落库」等工程黑话清理；「防 hindsight」「unplanned」等中英混杂改中文；Trail line / Entry line → 轨迹线 / 入场线；记录方式「Forward · 当时记录」→「当时记录 / 事后补录」。
- 计算口径说明一律挂 ⓘ 不常驻；原则宣言（「只摆事实，不打分」）只出现一次。
- 沉淀 `docs/copy-style.md` 文案与术语规范，后续所有 UI 文案以此为准。

## 7. 小功能

- 统计卡永远单行：大金额用 K/M/B 紧凑格式（$12.4K），悬停看完整值——「平均盈 / 亏」不再撑成两行。
- 所有资金曲线（总览 / 账户 / 周期）加均线开关：关 → MA(20 笔) → MA(30 天) 循环切换。

## 升级与兼容

- 浮窗脚本 `@version` 0.3.1：拆卡改勾选，对旧后端行为不变（自动降级单卡提交）；设置页可复制新版或从 GitHub 更新。
- 数据库无迁移；AI 建议/总结仍是版本化派生数据。
