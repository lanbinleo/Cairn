# CAIRN 0.2.2 Release Notes

0.2.2 是浮窗的可用性版本：卡片终于可以在 TradingView 里直接改错字了。配套的本地 API 修正路由、主题跟随和自定义仓位提示一起落地。

## 浮窗（脚本 0.2.4，需重贴脚本）

- **卡片行内修正**：每张卡右侧常驻 ✎，点开直接改原文（错字、语音误识别）和 BAR 序号（留空即清除）。原文修改旧表述自动进历史存档，AI 整理结果原样保留；旧版本 Cairn 不支持时会提示升级，编辑内容不丢。
- **Case 选择框修复**：下拉菜单的样式从初版就没有真正生效过（选择器从未命中），且菜单被面板裁切——现在外观与主题下拉一致，菜单完整展开。
- **主题三模式**（设置 → 外观）：跟随 TradingView（默认，自动切换）/ 深色 / 浅色。原生控件弹层、光标、滚动条一并跟随；浅色不是反色，是 TradingView 浅色色板。
- **仓位提示自定义**：风险条百分比从固定 1%/2% 改为最多三档自定义（设置 → 仓位提示，留空跳过），全部留空则不显示。
- 输入框全选/拖选修复（`user-select` 继承问题）；提交新卡时正在编辑的草稿不再丢失。

## 本地 API

- 新增 `PUT /api/v1/cases/{caseId}/cards/{cardId}`：卡片修正（body `{ rawText, barRef }`，`barRef: null` 清除、缺省保持），只动这两个字段，phase/创建时间/AI 分析原样保留；原文变化由后端统一版本化（`rawTextHistory` + `rawTextEditedAt`）。幂等 POST 重放仍拒绝改原文——刻意修正走 PUT。
- BAR 序号校验三处对齐为 1–1440（应用时间线 / REST API / 浮窗）：越界序号在入口即被拦下，不再等到时间线解析时才标异常。
- CORS `Access-Control-Allow-Methods` 补上 PUT（此前浏览器直连客户端的预检会被拒；油猴走 GM_xmlhttpRequest 不受影响）。

## Fixes（自 0.2.1）

- 浮窗 BAR 输入不再静默截断小数（`parseInt('38.5')` 曾存成 38）。
- 仓位提示百分比重复输入不再重复显示。
