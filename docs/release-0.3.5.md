# CAIRN 0.3.5 Release Notes

0.3.5 两件事：拆卡粒度按使用反馈再校准（0.3.4 的「宁细勿粗」把同一根 K 线上的评述拆出去了，改回 K 线锚定），以及把全部原生 confirm/alert 换成应用内的确认弹窗 + 右上角 toast 提示。无数据库迁移、无 schema 变化。

## 0. 拆卡粒度 v3：K 线锚定，宁合勿拆

0.3.4 的「独立的心智事件一张卡」矫枉过正：口述里提到一根 K 线后追加的市场分析、假设推演，被当成「独立观察」拆成了单独的卡——但交易者并没有说行情走到了下一根。v3 规则：

- **只有明确推进到新 K 线才开新卡**：显式报号（「120号K线」「BAR 120」），或已发生的事实陈述（「下一根 K 线收出了长上影」「立马跟着一根大阴线」）。
- **假设句式不是锚点**：「如果下一根突破我就放弃观察」「要是回到 120 我就……」是当前 K 线上的思考，留在上一张卡。
- **当前 K 线上的评述 / 分析 / 计划 / 情绪，不管几个想法都留在当前卡**——没说换 K 线就当作还在原来那根；中间实际隔了几根也不拆开，缺号不补、不猜。
- **机械兜底**：就算模型不听话仍拆出无锚点的段，校验层会把它并入前一张卡（开头引子并进第一张锚点卡）——无锚点的卡不可能存在。
- 输入时勾「拆卡」与「AI 重拆此卡」共用新规则：**0.3.4 拆过头的卡，现在点一次「AI 重拆此卡」就能收回去**（拆回一张时原卡不动并说明原因）；反过来，一根 K 线挤了多根内容的卡重拆后仍会按锚点分开。

拆卡 prompt 版本升级（`0.3.5-split-3`）；已有卡片不会被自动重拆。

## 1. 确认弹窗 + toast：告别浏览器原生弹窗

全部 16 处原生 `window.confirm`（删除 Case / 笔记 / 品种 / Provider / 账户 / Period / Trade / 卡片 / 标签、解除关联、重新生成 token、重新识别覆盖、重新填入备注、清空数据、AI 重拆）换成应用内确认弹窗：

- 样式与现有 Dialog 同语言；**破坏性动作为红色确认键**，Esc / 点外部一律等于取消（初始焦点落在取消键上）。
- 在已打开的编辑弹窗里点删除，确认弹窗会叠在上面，不会再闪出浏览器对话框。
- 文案规范：一句话问句 + 后果说明（「删除账户「X」？相关 Period 和 Trade 也会一起删除（可从备份恢复）。」），主按钮用动词原形。

新增右上角 toast 提示（sonner，压在标题栏之下）：

- **成功**：「已删除 Case」「已填入复盘备注」「已拆成 N 张卡」级别的轻提示，两三秒自动消失；备份导出 / 恢复 / 清空、保存网络与 API 配置、重新生成 token 等长操作结果都走这里。
- **失败 / 警告**：一句人话 + 下一步（遵循文案规范），此前静默吞掉的错误（如设置默认 Provider 失败）现在也会提示。
- 字段级校验、导入向导分步状态、AI 任务中心仍走就地展示，不弹 toast。

浮窗（TradingView 用户脚本 v0.3.2）同步跟进：卡片删除从原生 confirm 改为**行内两步确认**——第一次点 ✕ 按钮变红显示「确认删除」（4 秒后自动复位），再点一次才真正删除；成功仍是浮窗自己的小 toast。

## 升级与兼容

- 无数据迁移；拆卡行为变化只影响新拆分与手动重拆，存量卡片不动。
- 新增前端依赖 `sonner`（toast）；确认弹窗基于现有 Base UI Dialog 自建，无新 UI 依赖。
- 浮窗脚本 `@version` 0.3.1 → 0.3.2，设置页会提示 GitHub main 有新版（或直接复制内置新版）。
