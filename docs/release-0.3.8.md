# CAIRN 0.3.8 Release Notes

0.3.8 的主题是「入口顺手 + 深挖修复」：两处 UI 调整（复制表格按钮上移标题行、交易列表标题行新增手续费折叠开关），随后由四个维度的代码审查（前端计算 / 产品交互 / 安全 / Rust 数据层）挖出 38 项问题，确认 36 项全部修复。无数据库迁移、无 schema 变化。

## 1. 复制表格按钮上移标题行

- 「复制表格」从表格上方的小按钮移到各处标题同一排：交易页标题行、Dashboard「近期交易」卡头、Period 详情「交易」卡头，与「全部交易」等入口并列。
- 交易页的复制范围从「当前分页（20/40 笔）」改为「当前筛选的全部交易」——按钮在标题行代表整个列表，分页只是显示约束；toast 与元数据笔数随之按筛选总数。

## 2. 交易列表：手续费折叠开关

- 交易页标题行新增「手续费 ▾」折叠入口（Popover）：按账户列出「临时关闭手续费」开关，语义、提示与 toast 与账户详情页底部折叠区完全一致（费率保留、统计毛/净口径切换、导入的真实手续费不受影响）。
- 有账户处于临时关闭状态时按钮带「已临时关闭 N」标记；没有任何账户配置费率/导入手续费时不显示入口。
- 全 0 费率的账户按「未配置」处理，不再出现一行永久禁用的 0%/0% 开关。

## 3. 修复清单（按维度）

### 前端计算与状态（4 项）

- **AI 绑定候选排序反向（P1）**：候选池 comparator 方向反了——强匹配垫底，账户下未绑定对象超过 6 个时正确配对被挤出候选池，「AI 找 Case / AI 找 Trade」推荐失效或错推。已修正为强匹配优先，补排序/截断单测。
- **hydrate 写入竞态**：REST 写入触发的 data-changed 刷新若赶上一条还没提交的后台保存，会用旧快照整体覆盖内存，回滚刚保存的编辑。后台写入现在走串行队列，读库前先等队列清空。
- **删除级联的内存残留**：撤销导入 / 删 Period / 删账户后，指向已删 Trade 的绑定残留在内存里占用 Case、阻断重新绑定直到重启。已与 Rust 级联对齐。
- **导入同毫秒排序**：三行同刻跨单时排序比较器违反传递性，归组结果依赖输入排列；改为全序复合比较器（源编号 → entry/exit → 原始顺序）。

### 产品与交互（16 项，择要）

- 导入向导「确认导入」加锁定与「导入中…」反馈——连点不再整批重复导入。
- 中文输入法按 Enter 确认候选词不再误触发提交（AI 校对手动补对、Case 标题两处补 IME 防护）。
- **恢复备份补确认弹窗**：此前误选一个备份文件即静默整库替换。
- 导入向导：step3 人工关联失败现在显示错误；step2「上一步→下一步」文件没换时保留全部手动归组调整。
- 编辑 Trade 对话框不再清掉打开期间由外部（REST 绑定→Entry 卡回填）写入的计划价。
- 配图上传期间禁用删除、落库前重读最新列表——上传中删图不再被旧数据「复活」；配图删除补确认。
- 「全部识别」对手动修正过的卡改为先逐张确认再并发执行——并发确认框互相顶替会让被顶掉的卡静默跳过。
- 「编辑原文」菜单在编辑中显示「收起编辑」；切换编辑目标 / AI 重写遇未保存草稿先确认。
- 「过期」文案统一为「需重新识别 / 需重新总结 / 暂时忽略」。
- 高级筛选数字框可键入负号（R ≥ -1 不再只能粘贴）；标签重命名撞名有提示；任务中心点已删卡片任务有反馈；新建并关联失败重试不再重复建 Case。

### 安全（5 项修复 + 1 项待定）

- **REST 请求体上限**：鉴权前无上限读入完整请求体，恶意网页无需 token 即可把应用读爆内存；现在 Content-Length 超 2MB 或实际读出超限直接 413，空闲连接 60s 回收。
- **附件写路径防穿越**：`save_attachment_file` 的写路径此前没有读路径的防御，`..` 组件可写出 app data 目录；已补组件校验 + 目录边界复核。
- **附件读限定前缀**：`read_attachment_file` 此前可读 app data 根下任意文件（含明文 api_key 与 REST token）；现在限定 `attachments/` 下。
- **启用基础 CSP**（此前为 null）：脚本仅限自身，保留内联样式（图表库需要）、data/远程图片。
- api-config.json 损坏换新 token 时补日志（浮窗 401 有迹可循）。
- 待定：REST `Access-Control-Allow-Origin: *` 改 Origin 回显（widget 兼容性需实测，暂不动）。

### Rust 数据层与并发（10 项）

- **AI 重拆落库原子性（P1）**：软删原卡 + 建新卡 + 建议剔除此前分多次自动提交，中途失败留下半替换状态；已包进单事务。批量拆卡落库、级联软删同样补齐事务。
- **单行坏数据不再拖死全局**：一行损坏的 JSON 记录此前会让应用加载、备份、迁移全部失败；现在跳过并留痕。
- **panic 防护**：非对象 data 行此前会在持锁期间 panic 并毒化全局数据库锁；后台自动识别的并发闸门改 RAII，panic 不再泄漏配额、任务中心不再永远转圈。
- **单实例保护**：接入官方 single-instance 插件——主窗口收进托盘后再点 exe 不再拉起第二个进程互相覆盖写入；SQLite 加 busy_timeout。
- 备份在锁内只取快照、序列化写盘移出锁外（大数据量备份不再卡住所有界面操作）；批量拆卡落库前复核 Case 仍存活；AI 回填 barRef 补 1–1440 上限。

### 浮窗（`@version` 0.3.4）

- **单卡提交幂等**：单卡路径此前不带幂等 id，响应超时后重按会重复落卡；现在与拆卡同模式（同文本复用 id，成功即清除）。
- BAR 标记渲染改 textContent，不留 HTML 注入面。

## 升级与兼容

- 无数据迁移、无 schema 变化。
- 新增依赖：`tauri-plugin-single-instance`（官方插件，双开保护）。
- REST 行为变化：请求体超 2MB 返回 413（正常语音文本是 KB 级，无感）；`read_attachment_file` 限定 `attachments/` 前缀（GUI 渲染路径本就只用该前缀）。
- webview 启用 CSP：若升级后出现图片/图表不显示，请反馈——回滚只需把 `tauri.conf.json` 的 `csp` 置回 null。
- 浮窗脚本 0.3.4：更新走 设置 → 本地 API → 浮窗脚本（检查更新按钮），或重新复制安装。
