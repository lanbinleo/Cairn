# CAIRN 0.2.3 Release Notes

0.2.3 是浮窗脚本的分发版本：安装和更新脚本不再需要去仓库翻文件，设置页里直接复制。

## 浮窗脚本应用内分发

- **设置 → 本地 API → 浮窗脚本**：脚本内容编译进应用（`include_str!`），随应用更新而更新，点「复制脚本」粘贴进 Tampermonkey 即可，无需访问 GitHub。
- **自动对照 GitHub main**：每次打开设置页自动检查一次（走 `api.github.com`，本机网络通常可达）。GitHub 有新版时按钮变为「复制最新版」，复制的就是新版；版本一致则提示已是最新。
- 网络不通不影响使用——静默降级为复制内置版，附重试入口；检查失败的原因会打到控制台日志（`remoteError`），便于排障。
- 用户指南的脚本安装步骤改为从设置页复制；端点速查补上了 0.2.2 遗漏的 `PUT /api/v1/cases/{caseId}/cards/{cardId}` 修正路由。

## Fixes（自 0.2.2）

- 浮窗脚本更新检查的返回字段序列化修复：`builtinVersion`/`remoteNewer` 此前以 snake_case 返回，前端读到 undefined，导致新版提示永远不出现（本次功能在 0.2.3 内修复，未随任何版本发布）。
