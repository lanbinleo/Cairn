# CAIRN 0.3.7 Release Notes

0.3.7 的主题是「统计变真实 + 思路可编辑」：手续费进入所有统计口径（Taker/Maker 费率按账户配置、事后计提、全链净额追溯，可临时关闭对比毛口径），卡片原文从「错字修正」升级为完整编辑，并配了两个 AI 助手——AI 重写（出草稿、你来落笔）和 AI 校对（old→new 替换对逐条勾选）；交易表格支持一键复制（含元数据）。顺带修了跨午夜 Trade 的「昨天」前置卡渲染错位。无数据库迁移、无 schema 变化。

## 1. 手续费：所有 PnL 类指标改净额

此前所有盈亏都是毛口径——回测里赚的钱没扣过一分手续费。现在：

- **账户级 Taker / Maker 费率**（新建/编辑账户，百分比，如 0.05 / 0.02；留空不计）。按成交额逐笔计提（开平双边）：`手续费 = 成交价 × 数量 × 费率`。
- **订单分类有据**：导入一直在读的 Order Type 参与分档——market/stop 系按 Taker，limit/take-profit 按 Maker；某笔分类不对，编辑交易改 orderType 即纠正费档。
- **真实数据优先**：导出文件带 Commission/手续费 列时，每行实际手续费直接采用（`feeOverride`）；列里为 0 视为无数据、回落费率推算。
- **事后计提、追溯重算**：费率是配置不是记录——改一次费率，该账户全部历史统计立即按新费率重算。给已导入的回测历史补真实成本，就是这个用法。
- **净额贯穿**：PnL、胜率、Profit Factor、期望值、资金曲线、最大回撤、权益快照（浮窗余额随之变净额，浮窗零改动）、PnL% 分母、R 的分子、AI 总结上下文——全部按净额。R 的分母保持纯价格风险不掺手续费。费用把毛盈利吃成净亏损的笔会真实翻红。
- **展示**：交易详情复盘侧栏新增「手续费」行（悬停看毛盈亏）；评估 tab 在有费用时展示 毛盈亏 / 手续费 / 净盈亏 三行；交易列表不加列。

## 2. 编辑原文：写下来的思路是可编辑的

「修正原文错字」升级为「**编辑原文**」——不止错字，整段重写也行（语音原文里的口癖、废话、重复，现在可以理直气壮地清掉）：

- 大编辑器 + 一行提示：保存后原表述自动进历史存档（悬停卡片时间仍可看「已修正 N 次」的全部旧表述）；AI 识别照旧标「需重新识别」，一键重跑即锚定新文本。
- 编辑器带「恢复原文」；文本没变时保存按钮禁用（不产生空历史）。

## 3. AI 重写：草稿进编辑器，落笔永远是你

卡片 `···` 菜单新增「**AI 重写**」：

- AI 删掉口癖、语气词、重复与离题废话，保留第一人称语气与**每一个数字**（价格/数量/百分比/BAR 号/R 倍数，机械校验一个不丢，长度比限 30%–110%，失败自动修正一轮，仍失败报错不产半成品）。
- 草稿**不落库**——直接填进「编辑原文」编辑器，你过目、修改、保存才生效。AI 永远不直接改你的原文。

## 4. AI 校对：疑似错误逐条勾选

卡片 `···` 菜单新增「**AI 校对**」：

- 找「有把握是错误」的地方：错别字/口误/语音识别错误、数字与绑定交易事实明显不符（量级、位数）、BAR 号越界、方向词矛盾——只提有把握的，最多 10 条；没有发现就一句「AI 未发现明显错误」，不打扰。
- 校对对话框：每条 old → new 替换对附理由，逐条勾选；可手动补一对（实时校验原文中找得到）；底部实时预览套用后全文。
- 「套用 N 处修正」= 一次正常的原文编辑（历史入档、识别标过期）。被前一处替换覆盖的条目自动跳过并明示。

## 5. 手续费临时关闭 + 交易表格一键复制

- **临时关闭手续费**：账户详情页底部新增折叠的「手续费」区——展开是一枚「临时关闭手续费」开关。关闭后该账户全部统计（PnL / 胜率 / R / 权益曲线 / 浮窗余额）立即回到毛口径，费率配置原样保留，重新打开即恢复净额。平时收着不打扰，毛/净口径对比一键切换。
- **复制表格**：每张交易表格（交易页 / Dashboard 近期交易 / Period 详情）右上角新增「复制表格」——当前表格视图连同元数据（复制时间、笔数、账户、进场时间范围）复制为 TSV：粘进 Excel 是纯表格（`#` 开头的元数据行是注释），粘给 AI 复盘自带上下文；数值列是可解析的裸数字，PnL 按当前净额口径。

## 6. 修复：跨午夜 Trade 的「昨天」前置卡错位

复盘跨午夜的交易时，回顾前一晚 setup 的前置卡（BAR 号属于前一天）此前会被错误地扔到图表窗口起点、标成「BAR 异常」（生产 Trade#024：写着 270 的卡渲染在 212 附近）。现在 barRef 越窗时会先向前一天找——落回窗口内且不违反创建顺序就放到真实位置，昨天的抛售高潮终于出现在昨晚那根 K 线上。导入匹配行为不变。

## 升级与兼容

- 无数据迁移、无 schema 变化：Account 的费率字段与 Execution 的 `feeOverride` 走 JSON blob，旧数据自动视为「未配费率 = 不计」，一切数字与升级前一致；设置费率才开始净额。
- 新 GUI 命令：`draft_case_card_rewrite`、`proofread_case_card`（均 GUI only，无 REST/浮窗路由）。
- 浮窗脚本无变化（`@version` 保持 0.3.3）；权益快照变净额后浮窗余额自动跟随。
- 任务中心新增任务类型：AI 重写 / AI 校对。
