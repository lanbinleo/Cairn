# CAIRN 0.3.0 Release Notes

0.3.0 是「AI 秘书」版本：AI 从单卡整理升级为贯穿录入、对账、关联、复盘全程的助手。核心宗旨两条——不让用户再填一遍已经说过的话；该总结的地方让 AI 总结。设计哲学不变：原文永不改写（约束的是 AI，不是用户）、AI 结果是版本化派生数据、机械规则兜底、关键动作永远人工确认。

## 1. 卡片有一句话提炼了（digest）

- 每张卡的折叠行显示 AI 提炼的一句话（如「观察第三次测试上沿，倾向做空」），不再是口语原文的前 72 个字；原文点开照旧，一个字不改。
- AI 分析从此带背景上下文：品种、绑定交易的成交动作、同 Case 前几张卡的提要（此前每张卡都当第一张看）。分析质量与 memo 提取显著受益。
- 提示词经生产语料校准（口语变体、语音噪音、否定句式），schema 升至 `0.3.0-schema-3`；旧卡重新识别即可升级。

## 2. 浮窗批量拆卡（语音连续录入）

- 观察期一口气说一大段：「120号K线怎样……下一根……再下一根……」，提交一次自动按 K 线锚点拆成多张卡，BAR 自动填好（显式报号优先，「下一根」自动 +1，显式重报重置）。
- 不做预览确认——直接拆直接存，流畅优先；拆错了用 ✎ 改、✕ 删（见下）。
- 任何失败（AI 不可用/解析不通过）都退化为完整单卡，原文绝不丢；旧后端自动回退单卡提交。

## 3. 卡片可以删除了

- Case 页时间线与浮窗卡片列表都新增删除（软删，可从备份恢复），配套既有的改字/改 BAR/移动——用户调整权补全。「原文不可改」约束的是 AI，不是用户。

## 4. AI 建议 Execution（说了没落库对账）

- 绑定建立的那一刻（Case 先记、Trade 后导入的真实流程）自动检查：卡片里明确说过的止盈/止损/改单动作，成交记录里没有的，列出来待确认。
- 每条建议带证据：当时原话引用 + BAR + 机械换算时间。三个选择：直接添加 / 修改后添加（预填进编辑对话框）/ 忽略。
- 只做管理类动作；开仓平仓以交易所导入为准。机械去重（同分类同价 ±0.02% 视为已覆盖）；忽略过的建议重跑不再弹。

## 5. 整单 AI 总结

- Trade 关闭瞬间自动生成：计划怎么形成 → 怎么入场 → 持仓怎么管理 → 怎么离场，附要点与缺失信息。Trade 页复盘 Tab 顶部完整版，Case 页轻量摘要。
- 只摆事实与偏差，不打分不下结论——过程分永远是你自己评。
- 备注栏为空时可一键填入总结草稿再改；卡片后续有更新会提示总结过期。

## 6. 关联不靠肉眼翻

- Trade 页 Case 面板「AI 找 Case」、Case 页「AI 找 Trade」、导入第三步未匹配行：AI 拿卡片内容（方向/价格/时间）对未绑定对象排序并给理由，点确认才绑定。

## 7. 录入减负杂项

- Case 页新增卡的 BAR 不再必填：留空自动提取原文里的 BAR（与浮窗一致）。
- 浮窗 Entry 卡提交后，AI 的字段级缺失提醒会替换 0.2 的正则提示（「AI 整理：还缺 目标、失效条件」）。
- 顺手修复生产数据里发现的计划价污染：K 线号（64 号→入场价 64）和倍数（2~3 倍→止盈 2）不再被当价格提取（`firstPlausibleNumberIn` 数量级校验）。

## 8. 设置

- 设置 → AI「AI 行为」新增两个开关（默认开）：自动建议（绑定后对账 + 导入关联推荐）、自动整单总结。心疼 token 可关。

## 升级与兼容

- 浮窗脚本 `@version` 0.3.0：新功能（拆卡/删卡/缺字段提醒）对 0.2.x 后端自动降级并提示升级；设置页可复制新版或从 GitHub 更新。
- 数据库无迁移：建议与总结是 Case 记录上的版本化 JSON 派生数据；`ai-settings.json` 新字段带默认值，旧文件无需处理。
- AI 端点契约（REST）：新增 `DELETE /api/v1/cases/{caseId}/cards/{cardId}` 与 `POST /api/v1/cases/{caseId}/cards/batch-split`。

## 已知边界

- 批量拆卡的 AI 调用会占用本地 API 的请求线程（最长 90s×2，浮窗是唯一客户端且本来就在等提交），但数据库锁只在校验/落库时短持——主窗口操作不受影响。
- Execution 建议只认「明确价格或明确位置」的动作；「再拿一根看看」这类模糊表述不会进建议。只提到位置没报价格的建议走「修改后添加」补价后落库（直接添加不可用）。
- 本版不做 AI 打标签（标签七色有分类语义）与 AI 对话（总结+建议已覆盖其价值），留待后续版本。
