# CAIRN 0.3.2 Release Notes

0.3.2 是 AI 配置版：Provider 支持多模型切换、思考等级按厂商自动映射（不再只限智谱），外加全局出站代理。无数据库迁移、无 schema 变化。

## 0. Provider 多模型

- 一个 Provider 可保存多个模型（获取列表后点选添加，或手动输入），★ 标默认模型，随时切换——OpenRouter 上同时挂几个候选模型对比成为一等公民。
- 每个模型可单独设置思考等级，不设则跟随 Provider 默认。

## 1. 思考等级：按厂商自动映射

- 统一等级抽象（跟随模型默认 / 开启 / 关闭 / 低 / 中 / 高），按 Provider 自动翻译成各家的原生思考参数：
  - **OpenRouter**：`reasoning.effort`（低/中/高，官方推荐方式；关闭 = `none`）。
  - **OpenAI**：`reasoning_effort`（低/中/高）。
  - **智谱 GLM**：`thinking.type` 开/关。
  - **通义千问**：`enable_thinking` + `thinking_budget` 分档（低 2048 / 中 8192 / 高不设上限）。
  - **硅基流动**：`enable_thinking` 开/关。
- 不支持思考参数的厂商（DeepSeek、Gemini、Groq 等）界面不出现该选项，也不会发送未知字段——严格端点对未知字段直接 4xx 的坑不会再踩。
- 旧的「思考模式」设置自动升级为等级语义，行为不变（开/关照旧生效）。

## 2. 出站代理

- 设置新增「网络」页：AI 调用与浮窗脚本更新检查可走代理服务器，默认地址预填 `http://127.0.0.1:7890`（Clash 常用端口），开关默认关闭。
- 保存即生效，无需重启；代理地址失效时自动降级直连，不会卡死全部请求。应用内更新检查走系统通道，不受此设置影响。

## 升级与兼容

- 旧的 `ai-providers.json` 自动兼容：原默认模型合成为单元素模型列表，配置不丢。
- 凭证与代理设置仍只保存在本机，不进入备份。
