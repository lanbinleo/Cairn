# CAIRN 0.3.3 Release Notes

0.3.3 是修复版：出站网络全走系统代理（含应用内更新）、导入匹配算法按生产数据重做、GLM 思考参数修复、AI 任务中心失败可确认、默认 Provider 点击即选。无数据库迁移、无 schema 变化。

## 0. 出站代理：跟随系统 + 更新器全覆盖

- 「网络」设置改为三档：**跟随系统代理**（默认，自动读操作系统代理设置）/ 手动指定 / 直连。
- **应用内更新检查现在同样走代理**——之前更新器走独立通道，代理只覆盖 AI 与 GitHub 检查。
- 所有 Rust 出站请求（AI、GitHub 浮窗脚本检查、更新检查）统一经过同一代理解析；系统未配置代理时自动直连，代理失效降级直连不卡请求。
- 0.3.2 的旧配置自动迁移：原来开关开启的变「手动指定」，原来关闭的变「跟随系统代理」。
- 跟随系统模式下界面会显示当前探测到的代理地址，方便确认。

## 1. 导入匹配算法重做（回放工作流可自动关联）

旧算法拿卡片录制时间（墙钟）与 Trade 成交时间（图表时间）比对——回放/复盘场景下两者相差数月，永远匹配不上（生产六对绑定全部靠手动）。新算法：

- **图表轴（主）**：Entry/Closing 卡的 BAR 锚定到 Trade 首笔成交所在 UTC 日换算成图表时间，与开/平仓时间比对；1/5/15/30/60 分钟周期自动扫描。挂单决策卡允许领先成交最多 30 分钟。
- **价格佐证**：Entry 卡里的止损/止盈/入场价与 Trade 的初始止损/止盈/均价比对（0.2% 容差）——生产样本多对逐位一致。
- **方向冲突不自动绑定**：卡里说的方向和 Trade 方向相反时只进黄色建议。
- **墙钟轴（兜底）**：当场内实时记录时沿用原容差窗口。
- 语音录入的小回退（BAR 序号略小于前一张，如 153 后念 152）不再触发跨日推断污染后续卡片。
- 多对同强时按质量全局分配（离场命中 > 价格佐证 > 时间距离），完全并列的留给人工确认。
- 生产数据回放验证：6 对已绑定样本全部自动命中，16 笔无关 Trade 零误绑定。「AI 找 Case / AI 找 Trade」的候选排序同步受益。

## 2. GLM 思考参数修复

- 官方文档 + 实测确认：**GLM-5.3 / GLM-5.3-FLASH 不支持关闭思考**（发 `disabled` 直接 400「该模型始终思考，不支持关闭思考；请使用 low、high 或 max」）。对这类模型，「关闭思考」自动降级为最低档 `low`，界面也不再提供关闭选项。
- 智谱 GLM 补上 `reasoning_effort` 分档（低 / 高），低档实测显著省 token。

## 3. AI 任务中心：失败可确认

- 失败任务展开原因后有「知道了，不再提示」，行尾也有 ✕——确认后从列表移除，侧栏不再顶着失败图标提醒已知问题。

## 4. 默认 Provider 点击即选

- 设置 → AI 的 Provider 列表：点击卡片直接选为默认（选中卡片有一圈边框高亮），不再进编辑对话框勾选。
- 编辑 Provider 不再影响默认标记（此前「打开另一个保存一下」可能把默认标记挤掉的隐患一并修复）。

## 升级与兼容

- `network-settings.json` 旧格式自动迁移；代理与凭证设置仍只保存在本机，不进入备份。
- 匹配算法升级无需任何数据迁移，只影响导入时的推荐与自动绑定。
