# CAIRN 0.2.1 Release Notes

0.2.1 是首个真实复盘流程跑通后的修复与增强版本：BAR 跨天解析在回放/复盘场景下彻底重做，AI 从「手动点」变成「自动跑 + 可修正」，风险可见性进入浮窗和交易列表。同时包含 0.2.0 发布后积累的浮窗键盘修复（0.2.2 待验证内容已并入本版）与用户教程。

## Case Card 与 BAR 解析

- 跨天 barRef 解析改锚定 Trade 首笔成交日：回放/复盘时卡片创建时间与图表日期无关，旧算法会整案错位；现在记录顺序优先于 bar 数学。
- 语音误识别的越界序号（如 265 听成 2265）不再毒化整条时间线：越界值不参与推导并标记「BAR 异常」，BAR 徽章点开即可修正（或补填缺 BAR 的卡）。
- 图表减负：同一根 K 线上的多张 Case 卡合并为一个方块（×N，悬停看全部）；方块不再印 BAR 文字；图表范围外的标记不再吸附到图末端；价格标签统一精度（90618.85999999999 → 90618.86）。
- 冰山拆单识别：同一根 K 线同价同时的同向成交合并为一笔（`Entry (2)`）——一次下单被交易所拆成的 fill 不再显示成「入场 + 加仓」。

## AI 秘书自动化

- 逐卡自动整理：浮窗/本地 API 提交新卡后后台自动识别（设置 → AI 可关；幂等重放不触发；失败自动重试一次后只记日志，不打扰录制）。
- 所有 AI 请求失败自动重试一次（仅网络类：超时/5xx/空回复）。
- 绑定 Trade 后自动拟题：仅替换默认占位标题，你起过的名字永不覆盖。
- AI 结果全部可修正：BAR 序号、memo 字段（缺失清单机械重算）、原文标签（点彩色下划线改/删，选中原文打新标签）——改的是整理结果，原文一字不动；重新识别前会确认避免覆盖手动调整。
- memo 新增第七字段「入场价」（schema v2）；「已过期」徽章可一键忽略本次过期。

## 复盘体验

- 心路历程组件统一：Trade 页 Case 标签下的卡片与 Case 页完全同权——可编辑原文、重新识别、改 BAR、整理标签。
- 卡片默认折叠为一行摘要，支持全部展开/收起；几十张卡的 Case 一屏可读。
- Case 页顶部新增概要条（状态、绑定 Trade、五阶段卡片数、更新时间），新增 Card 表单收进折叠面板。
- 计划 vs 实际新增「入场价」行，每个计划值标注来源（录=补录 / 卡=memo）；绑定后空缺计划价自动从 Entry 卡回填，绝不覆盖已填值。
- 已平仓 Trade 缺初始止损/止盈时首次访问弹提醒：从 Entry 卡填入 / 手动填写 / 待会儿提醒 / 忽略。

## 风险可见性

- 浮窗显示当前余额与 1% / 2% 固定风险额（权益 = 初始资金 + 已平仓盈亏，无快照时显示初始资金并标注）。
- 交易列表在 PnL 与 R 之间新增 PnL% 列：这笔盈亏占当时仓位权益的百分比，固定风险额习惯下可直接识别超风险或高盈亏比交易。

## 基础设施

- 前端引入 vitest（`pnpm test`）：bar-time 与 execution-display 单测，含生产 25 卡跨天序列全量回放用例。
- **启用应用内自动更新**：签名私钥其实一直在本机（`%USERPROFILE%\.tauri\cairn-updater.key`，与 v0.1.3 起内嵌的公钥配对），此前缺的只是构建签名与 `latest.json` 清单。现在 `pnpm release:check x.y.z -BuildInstaller` 自动完成签名构建并生成 `latest.json`；发布时上传 setup.exe / msi / latest.json 三个资产后，设置 → 关于 → 检查更新 即可升级。**已安装的 v0.2.0 可以直接应用内更新到 0.2.1。**

## Fixes（自 0.2.0）

- 浮窗键盘隔离两轮修复（冒泡截断 → window 捕获拦截）与 light DOM 渲染（0.2.0 后合入，随本版发布）。
- 跨天 case card BAR 解析按创建顺序单调推进（8459808，被本版新算法取代）。
