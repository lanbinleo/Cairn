# CAIRN 0.3.4 Release Notes

0.3.4 围绕 AI 能力：拆卡粒度按生产数据重做 + 已有卡片可「AI 重拆此卡」、AI 交易标签建议（评级即标签）、AI 总结重点标注（加粗 + 红绿下划线）、过程分筛选与侧栏展示。无数据库迁移、无 schema 变化。

## 0. 拆卡粒度重做 + 「AI 重拆此卡」

生产数据里 79 张活卡中 35 张是过程阶段的连续评述（最长 1692 字，一根 K 线一个想法全挤在一张卡里），而且就算勾了「拆卡」，拆出来的卡仍然偏粗。两层修复：

- **拆分粒度 v2**：prompt 从「单一主题一张卡」改为「**一个独立的心智事件一张卡**」——逐根 K 线的评述按观察点分开，围绕同一根 K 线/同一个想法连续说的几句话保持一张，不按句子硬切。输入时勾「拆卡」同样受益。
- **AI 重拆此卡（复盘场景）**：任何一张已有卡片的 `···` 菜单（Case 页与 Trade 案例页共用）新增「AI 重拆此卡」——确认一次即拆分替换。原卡软删除（可从备份恢复），新卡按原位置落位（首张继承 entryDecision 和 BAR），AI 识别自动重跑，结果进 AI 任务中心。
- **拆不动就不动**：AI 不可用、拆分校验不过、或 AI 认为是一段完整记录时，原卡原样保留并提示原因——重拆是破坏性替换，绝不「退化成原样还丢分析」。

## 1. AI 交易标签建议

关联 Case 之后，AI 在「AI 补录建议」正下方多了一块「AI 标签建议」：

- **只用你自己的标签**：候选全部来自你的标签词表，按你的颜色分组语义喂给 AI（红=定调整笔交易、黄=市场结构、绿=仓位与执行、青=复盘状态、蓝=情绪、紫=特殊标注、橙=顺势/周期），不许造新标签。
- **每条都有原话证据**：证据引语必须逐字来自卡片原文（Rust 逐条校验），点击跳到对应卡片。
- **一次检查、两份候选**：与补录建议同一次 AI 调用产出，上限 15 条、按证据强度排序；逐条 应用/忽略，或「全部应用」。应用到 Trade 上由你确认，处理完折叠成一小条。
- **评级即标签**：A 级交易本来就是你词表里的红色标签——想用评级，把「AA级交易」「AAA级交易」建为红色标签即可，AI 会按证据建议它们，筛选用现成的标签筛选。

## 2. AI 总结重点标注

- 总结正文现在可以带受限标注：**加粗**（关键事实）、<u style="text-decoration-color:#f87171">红色下划线</u>（问题/偏差）、<u style="text-decoration-color:#4ade80">绿色下划线</u>（执行到位/亮点）——扫一眼就能看到哪里出问题、哪里做对了。
- 标注克制使用（prompt 限制全文 ≤15 处）；Rust 侧清洗未配对/空/跨段/嵌套的标记，文字永不丢。
- 「填入复盘备注」自动剥离标注（备注是纯文本）；旧总结不受影响。
- 已有总结想用新标注：点一次「重新总结」即可。

## 3. 过程分：已评分筛选 + 侧栏展示

- 交易列表筛选新增「**已评分**」（与「未评分」并列，互斥）。
- Trade 复盘侧栏「结果」卡新增单行**过程分 x / 10**；未评分时显示「未评分，去评分」直达评估页。
- 交易列表不加新列（已经很挤）；评过分的交易一眼可见。

## 升级与兼容

- 无数据迁移：新建议 blob（`aiTagSuggestions`）随下一次检查自动生成；总结标注在重新总结后出现。
- 拆卡 prompt 版本升级（`0.3.4-split-2`），输入时拆卡与重拆共用；已有卡片不会被自动重拆。

## 发布前 Code Review 修复

- **「全部应用」丢标签**：AI 标签建议一次应用多条时，只有最后一条真正落到 Trade 上（`updateTrade` 的 tags 是整体替换，逐条同步提交互相覆盖）。已改为一次提交全部名字（`tagsWithAdditions`，带单测）。
- **系统代理关闭后残留地址误判**（0.3.3 引入）：Windows 关掉系统代理开关后注册表仍保留旧 `ProxyServer` 值，「跟随系统代理」会探测到这个死代理，导致 AI / 更新检查全部超时。现在 `enable=false` 一律视为无代理（`system_proxy_url`，带单测）。
